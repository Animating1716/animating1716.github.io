Datenschutzerklärung Grog Recorder

Grog Recorder ist eine private App für den persönlichen Gebrauch von Joshua Zoeller.

Die App nimmt Audio auf dem iPhone auf und lädt die Aufnahmen über die Google Drive API ausschließlich in das Google-Drive-Konto des angemeldeten Nutzers hoch. Sie nutzt nur die Berechtigung drive.file und greift damit nur auf Dateien und Ordner zu, die sie selbst erstellt hat.

Es gibt keine Server des Entwicklers, keine Analyse, kein Tracking und keine Weitergabe an Dritte. Der Anmeldezugang wird nur lokal auf dem Gerät gespeichert. Die Nutzung von Google-Daten entspricht der Google API Services User Data Policy einschließlich der Limited-Use-Anforderungen.
